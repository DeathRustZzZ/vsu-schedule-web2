Создать удобную, масштабируемую и легко поддерживаемую систему навигации для Telegram бота с использованием Inline меню.

## 💻 Примеры кода

### Использование главного меню
```rust
bot.send_message(chat_id, "Выберите действие:")
    .reply_markup(menu::main_menu_inline_keyboard())
    .await?
```

### Редактирование меню
```rust
bot.edit_message_text(chat_id, msg_id, "Обновлено:")
    .reply_markup(menu::menu_two_column_keyboard(&[
        MenuCommand::MyProfile,
        MenuCommand::MySchedule,
    ]))
    .await?
```

### Обработка команды
```rust
MenuDispatcher::dispatch(&context, MenuCommand::MyProfile).await?
```
