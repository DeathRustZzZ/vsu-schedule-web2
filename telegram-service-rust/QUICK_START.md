## ✅ Шаг 3: Установка переменных окружения (1 минута)

Создайте файл `.env` в корне проекта:

```bash
cat > .env << 'EOF'
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=postgresql://user:password@localhost/tg_bot_vsu
RUST_LOG=info
EOF
```
