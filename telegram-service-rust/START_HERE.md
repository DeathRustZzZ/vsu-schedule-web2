## 🎯 Основные концепции

### MenuCommand (7 типов)
```rust
pub enum MenuCommand {
    MainMenu,      // 🏠 Главное меню
    Register,      // 📝 Зарегистрироваться
    MyProfile,     // 👤 Мой профиль
    MySchedule,    // 📅 Моё расписание
    ChooseGroup,   // 👥 Выбрать группу
    Back,          // ◀️ Назад
    Help,          // ❓ Справка
}
```

### Типичный поток
```
Пользователь пишет сообщение
    ↓
handle_message() проверяет, зарегистрирован ли он
    ↓
Отправляет соответствующее меню
    ↓
Пользователь нажимает кнопку
    ↓
callback_router маршрутизирует запрос
    ↓
MenuDispatcher обрабатывает команду
    ↓
Отправляет обновленное сообщение
```

## 🔧 Типичные операции

### Отправить главное меню
```rust
bot.send_message(chat_id, "Выбери действие:")
    .reply_markup(menu::main_menu_inline_keyboard())
    .await?
```

### Создать двухколоночное меню
```rust
let commands = vec![MenuCommand::MyProfile, MenuCommand::MySchedule];
let keyboard = menu::menu_two_column_keyboard(&commands);
```

### Меню с кнопкой "Назад"
```rust
let commands = vec![MenuCommand::Register];
let keyboard = menu::menu_with_back_keyboard(&commands);
```

## 🚨 Важные моменты

### Type Safety
✅ **Используйте enum вместо строк!**
```rust
// ❌ Плохо
let callback: String = "menu_register";

// ✅ Хорошо
let command = MenuCommand::Register;
```

### Логирование
✅ **Все команды логируются автоматически**
```rust
info!("📍 Переход в главное меню пользователем {}", user_id);
```

### Обработка ошибок
✅ **Используйте Result типы**
```rust
MenuDispatcher::dispatch(&context, command).await?
```

## 🔍 Структура кода

### src/domain/menu.rs
Определяет типы данных. **НЕ ТРОГАЙТЕ БЕЗ НЕОБХОДИМОСТИ!**

### src/services/telegram/callback_router.rs
Маршрутизатор. Обновлён для работы с новой системой.
