## 🎓 Учебный материал

### Для изучения Rust + Telegram Bot разработки
1. Изучите ARCHITECTURE.md для понимания паттернов
2. Посмотрите EXAMPLES.md для примеров Rust кода
3. Смотрите исходный код в src/ с doc-комментариями

### Для изучения Clean Architecture
1. Прочитайте ARCHITECTURE.md - раздел "Слои архитектуры"
2. Посмотрите на разделение в src/:
   - `domain/` - бизнес-логика
   - `services/` - интеграции
   - `db/` - доступ к данным
   - `app/` - инициализация

### Для изучения асинхронного Rust
1. Смотрите EXAMPLES.md - примеры с async/await
2. Посмотрите handlers в src/services/telegram/
